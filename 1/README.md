# 🏥 سیستم ثبت رفت و آمد پرسنل داروخانه

برنامه دسکتاپ ثبت و مدیریت رفت و آمد پرسنل داروخانه (حداکثر ۱۰ نفر)
با رابط کاربری مدرن، تم روشن/تاریک و پشتیبانی کامل از تقویم شمسی.

---

## ✨ امکانات

- ✅ ثبت ورود/خروج با کد پرسنلی + پشتیبانی از چند شیفت در یک روز
- ✅ مدیریت کاربران (افزودن / ویرایش / غیرفعال‌سازی) با حداکثر ۱۰ پرسنل
- ✅ گزارش‌گیری با فیلتر تاریخ/ساعت/کاربر/سمت + خروجی CSV و PDF فارسی
- ✅ مدیریت تردد (افزودن / ویرایش / حذف با تأیید)
- ✅ تغییر رمز مدیر با هش امن (PBKDF2-SHA256 + Salt)
- ✅ قفل خودکار دسترسی مدیر پس از ۵ دقیقه بی‌کاری
- ✅ تم روشن و تاریک با یک کلیک
- ✅ رابط کاربری RTL با اعداد LTR
- ✅ ساعت زنده تهران با دو لینک API + Fallback
- ✅ نمایش وضعیت شبکه: 🟢 آنلاین / 🟡 ذخیره‌شده / 🔴 آفلاین
- ✅ ورودی تاریخ شمسی سه‌کادری با پرش خودکار
- ✅ ورودی ساعت دوکادری با پرش خودکار

## 📦 نصب

### 1. کلون یا دانلود پروژه

پروژه را در یک پوشه مانند `pharmacy_attendance` قرار دهید.

### 2. ساخت محیط مجازی (توصیه می‌شود)

```bash
python -m venv venv
venv\Scripts\activate       # ویندوز
# source venv/bin/activate  # لینوکس / مک
```

### 3. نصب پکیج‌ها

```bash
pip install -r requirements.txt
```

### 4. افزودن فونت وزیرمتن (برای PDF فارسی)

فایل `Vazirmatn-Regular.ttf` را در مسیر زیر قرار دهید:

```
assets/fonts/Vazirmatn-Regular.ttf
```

می‌توانید از سایت رسمی دریافت کنید:
[https://github.com/rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn)

> اگر فایل فونت نباشد، PDF با فونت پیش‌فرض ساخته می‌شود ولی ممکن است فارسی درست نمایش داده نشود.

### 5. اجرا

```bash
python main.py
```

## 🎯 نکات استفاده

### ثبت ورود/خروج (صفحه ۱)
1. کد پرسنلی را وارد کرده و **Enter** بزنید.
2. اطلاعات پرسنل نمایش داده می‌شود.
3. نوع تردد به‌صورت هوشمند پیشنهاد می‌شود.
4. دکمه **ثبت** یا **Enter** را بزنید.

### پشتیبانی از چند شیفت
اگر امروز یک شیفت کامل ثبت شده باشد، می‌توانید شیفت جدید (ورود مجدد) ثبت کنید.

### دسترسی مدیر
- روی دکمه **🔐 ورود مدیر** در نوار بالا کلیک کنید.
- رمز پیش‌فرض: `1234`
- پس از ۵ دقیقه بی‌کاری، دسترسی خودکار قفل می‌شود.

### خروجی‌ها
- **CSV**: با UTF-8-sig برای Excel فارسی
- **PDF**: با فونت وزیرمتن و چیدمان RTL

## 🐛 رفع مشکلات رایج

### 1. خطای Import
مطمئن شوید که از **ریشه پوشه پروژه** اجرا می‌کنید:
```bash
cd pharmacy_attendance
python main.py
```

### 2. فارسی در PDF نمایش داده نمی‌شود
فایل `Vazirmatn-Regular.ttf` را در `assets/fonts/` قرار دهید.

### 3. ساعت تهران اشتباه است

- برای بروزرسانی، اینترنت را وصل کنید و برنامه را ری‌استارت کنید.
